FINTRACK RUN INSTRUCTIONS

Do NOT open HTML files directly from inside the ZIP archive.

1. Extract the complete ZIP to a normal folder.
2. Open START_FINTRACK.bat.
3. The user login page opens at:
   http://localhost:5500/user/user-login.html

The project uses relative CSS and JavaScript paths. Opening an HTML file from an archive/temp preview can cause CSS/JS files to be unavailable, producing an unstyled page or ERR_FILE_NOT_FOUND.

Alternative:
- Open a terminal in this folder.
- Run: python -m http.server 5500
- Open: http://localhost:5500/user/user-login.html
